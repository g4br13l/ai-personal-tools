# Make Transcription

## Purpose

Use this skill to turn a local MP4 into:

- `%VIDEO_PATH%_audio.wav`
- `%VIDEO_PATH%_audio.srt`
- `%VIDEO_PATH%_transcript_flat.txt`
- `%VIDEO_PATH%_speaker_transcript.txt`

## Prerequisites

- `ffmpeg` installed and available on `PATH`.
- `whisper` CLI installed and callable.
- Whisper model file at `C:/ai/models/ggml-large-v3-turbo.bin`.
- A readable local MP4 file.

## Execution rules

- Execute all 4 steps. None are optional.
- Execute them sequentially: Step 1, then Step 2, then Step 3, then Step 4.
- Do not skip, merge, reorder, or stop after Step 3.
- Before starting the next step, verify the current step passed its validation checks.
- If an input is missing or a validation check fails, stop and resolve that issue before continuing.
- Read the linked reference file immediately before executing each step.

## Workflow

### Step 1: Collect required input

Read [references/step-1-ask-input.md](references/step-1-ask-input.md).

Obtain `%VIDEO_PATH%` and `%VIDEO_LANG%`.
Do not continue until both values are known and valid.

### Step 2: Convert MP4 to WAV

Read [references/step-2-convert-wav.md](references/step-2-convert-wav.md).

Run:

```powershell
ffmpeg -i "%VIDEO_PATH%" -ar 16000 -ac 1 -c:a pcm_s16le "%VIDEO_PATH%_audio.wav"
```

Do not continue until the WAV file exists and passes validation.

### Step 3: Generate transcription with Whisper

Read [references/step-3-whisper-transcription.md](references/step-3-whisper-transcription.md).

Run:

```powershell
whisper -m "C:/ai/models/ggml-large-v3-turbo.bin" -f "%VIDEO_PATH%_audio.wav" -l %VIDEO_LANG% -bs 5 -osrt --prompt "Transcription of an interview, job interview, or technical software development discussion."
```

Do not continue until `%VIDEO_PATH%_audio.srt` exists and passes validation.

### Step 4: Create speaker-labeled transcript

Read [references/step-4-speaker-inference.md](references/step-4-speaker-inference.md).

Use [references/speaker-diarization-prompt.md](references/speaker-diarization-prompt.md) to transform `%VIDEO_PATH%_transcript_flat.txt` into `%VIDEO_PATH%_speaker_transcript.txt`.
Do not finish until the speaker-labeled transcript exists and passes validation.

## Expected outputs

| Artifact | Description |
|----------|-------------|
| `%VIDEO_PATH%_audio.wav` | 16 kHz mono WAV derived from the MP4 |
| `%VIDEO_PATH%_audio.srt` | Timestamped subtitle file generated by Whisper |
| `%VIDEO_PATH%_transcript_flat.txt` | Flattened transcript with one `[HH:MM:SS] text` line per subtitle |
| `%VIDEO_PATH%_speaker_transcript.txt` | Speaker-labeled transcript preserving original timestamps |

## Completion criteria

- All four output artifacts exist.
- The `.srt` timestamps are sequential and increasing.
- The flattened transcript preserves timestamp order.
- The speaker-labeled transcript preserves timestamp order and uses `Speaker N` labels.

## Troubleshooting

- Noisy transcription: verify the WAV is truly mono; re-run `ffmpeg`.
- Low quality: test with a shorter clip; simplify `--prompt`.
- Timestamp drift: compare WAV length with the source video; re-run conversion with the same sample-rate settings.
- Wrong names or terms: tune `--prompt` with 1-2 representative sentences.
